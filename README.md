# Super-Power Memory Gym

A browser game for practising the memory systems in Harry Lorayne's *How to Develop a Super-Power Memory*, one tip and one level at a time.

**Play:** https://rth36.github.io/memory-gym/

## What's inside

15 tips in the book's order, each with levels, stars, XP and real-life "field missions":

1. Observation
2. The Link Method
3. The Phonetic Alphabet
4. Peg Words (1–100)
5. Remembering by Number
6. Emergency Pegs (alphabet and number-shape pegs)
7. Long Numbers
8. Playing Cards (including the missing-card stunt)
9. Dates and the Calendar
10. Substitute Words
11. Names and Faces
12. Telephone Numbers
13. Appointments
14. Speeches and Articles
15. Absent-mindedness

Score 80% to pass a level, 90% for two stars, 100% for three. Progress is saved in your browser's local storage.

It's a single self-contained `index.html` with no build step. Open it in a browser to play.
